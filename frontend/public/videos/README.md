首页背景使用 `showroom-08.mp4`，静音、内联、循环、可暂停，离屏或隐藏标签时暂停。背景按 `cover` 铺满，完整影片在下方播放器观看。

原始 4K 视频已压缩为网页版本，避免超过 GitHub 单文件大小限制；其余竖屏视频直接保留了较小体积版本。
